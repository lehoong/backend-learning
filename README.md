# Backend Learning

Repository ghi lại quá trình học Backend Development bằng Python.

## Mục tiêu

- Nắm vững Python cho Backend
- Hiểu HTTP và REST API
- Xây API bằng FastAPI
- Sử dụng PostgreSQL và SQLAlchemy
- Viết test bằng pytest
- Sử dụng Docker
- Hoàn thành đồ án Prompt/SQL-to-CSV

## Cấu trúc

- `exercises/`: bài tập theo tuần
- `projects/`: các mini project
- `notes/`: ghi chú kiến thức
- `weekly-reviews/`: đánh giá tiến độ mỗi tuần
